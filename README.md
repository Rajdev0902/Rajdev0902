## About Me

I am a Senior Azure DevOps Engineer with 6.9 years of total IT experience, including approximately 4.3 years of hands-on DevOps and DevSecOps experience.

My focus is on designing and automating cloud infrastructure, building secure CI/CD pipelines, and improving deployment reliability through Infrastructure as Code and cloud-native technologies.

- **Cloud:** Microsoft Azure
- **Infrastructure as Code:** Terraform, reusable modules, remote state management
- **CI/CD:** Azure DevOps, YAML pipelines, Git, branching strategies
- **Containers:** Docker, Kubernetes, Azure Kubernetes Service (AKS), Azure Container Registry (ACR)
- **DevSecOps:** SonarQube, Trivy, Checkov, TFLint, secret scanning
- **Networking:** VNets, subnets, NSGs, private endpoints, Azure Firewall
- **Monitoring:** Prometheus, Grafana, Azure Monitor
- **Automation:** Bash, PowerShell, Azure CLI
