## How I approach delivery

::: {align="center"}
  -----------------------------------------------------------------------
  01 · Plan         02 · Provision    03 · Protect      04 · Operate
  ----------------- ----------------- ----------------- -----------------
  Review changes    Reusable          Shift-left        Monitor and
                    Terraform         scanning          troubleshoot

  PR and standards  Validate and plan Secrets and image Improve
                                      checks            reliability
  -----------------------------------------------------------------------
:::

-   Keep infrastructure changes version-controlled and reviewable.
-   Run formatting, validation, linting, and security checks before
    deployment.
-   Protect credentials; use managed identity and Key Vault patterns
    where appropriate.
-   Prefer least-privilege access and private connectivity where the
    architecture requires it.
-   Document deployment, rollback, and recovery procedures.
