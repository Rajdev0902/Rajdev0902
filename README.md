Engineering principles
- Prefer reusable, reviewable infrastructure over manual
  configuration.
- Keep secrets out of source code and pipeline logs.
- Validate Terraform changes before applying them.
- Use least-privilege access and private connectivity where
  appropriate.
- Make deployments observable and troubleshooting repeatable.
- Document architecture, assumptions, recovery steps, and operational
  trade-offs.
