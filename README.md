## About Me

I am a Senior Azure DevOps Engineer with **6.9 years of total IT experience**, including approximately **4.3 years in DevOps and DevSecOps**.

My focus is on automating cloud infrastructure, implementing secure CI/CD pipelines, and improving the reliability and repeatability of application deployments using Infrastructure as Code and cloud-native technologies.

- ☁️ **Cloud:** Microsoft Azure
- 🏗️ **Infrastructure as Code:** Terraform, reusable modules, remote state
- 🔄 **CI/CD:** Azure DevOps, YAML pipelines, Git workflows
- 🐳 **Containers:** Docker, Kubernetes, AKS, ACR
- 🔐 **DevSecOps:** SonarQube, Trivy, Checkov, TFLint, secret scanning
- 🌐 **Networking:** VNets, subnets, NSGs, private endpoints, Azure Firewall
- 📊 **Monitoring:** Prometheus, Grafana, Azure Monitor
- ⚙️ **Automation:** Bash, PowerShell, Azure CLI

## 🏗️ Terraform & Infrastructure as Code

- Developing reusable, parameterized Terraform modules.
- Provisioning Azure networking, compute, storage and platform resources.
- Managing remote state using Azure Blob Storage.
- Implementing `terraform fmt`, `validate`, `plan` and controlled `apply` workflows.
- Understanding state locking, drift detection, imports and recovery.
- Separating environments and managing infrastructure changes through version control.
- Integrating infrastructure validation and security scanning into CI/CD.

## 🔄 Azure DevOps & CI/CD

- Designing YAML-based build and deployment pipelines.
- Automating Terraform validation, planning and deployment.
- Integrating peer reviews, branch policies and approval gates.
- Building Docker images and publishing them to Azure Container Registry.
- Deploying containerized workloads to AKS.
- Managing pipeline variables, secrets and secure service connections.
- Integrating code quality, vulnerability and IaC security scans.
